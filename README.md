# 🌸 Iris & Shapes Classifier Web App

This project is a web application that allows users to:
* Predict Iris flower species using input features (uses Scikit Learn)
* Classify shapes from uploaded images (uses Keras for Classification)

## 🚀 Tech Stack
* Flask (Frontend)
* Connexion / OpenAPI (Backend API)
* Machine Learning models

## ▶️ How to Run
### 1. Clone the repository
git clone https://github.com/Dhivya-fullstack/Iris-Shapes-Classifier.git

### 2. Navigate to project folder
cd iris-shapes-classifier

### 3. Create virtual environment
python -m venv venv

### 4. Activate virtual environment
venv\Scripts\activate   (Windows)

### 5. Install dependencies
pip install -r requirements.txt

### 6. Run backend (API)
python app.py

### 7. Run frontend (Flask)
flask --app app.py run

### 8. Open browser
http://127.0.0.1:5000/

## 📌 Features
* Iris prediction using numerical inputs
* Shape classification using image upload
* REST API with OpenAPI specification
